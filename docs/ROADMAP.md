# Roadmap

This document records future project work. The eight Labs listed in the root README are the initial public content; their local READMEs are the source of truth for the challenges that exist today.

## Future directions

- Add community-authored Easy, Intermediate, Advanced and specialised challenges to any existing Lab.
- Improve shared templates and lightweight checks for README structure, links, reproducibility and secret hygiene.
- Add optional community Labs for stacks such as NestJS, Go, Rust or platform engineering when a maintainer can provide a deterministic local path.
- Improve accessibility, translations and discoverability without turning the catalogue into a progress board.
- Consider a documentation site or release process once maintenance needs justify it.

## Design constraints

Future work follows [LAB_SPEC](LAB_SPEC.md) and the [Interview Research & Editorial Guide](INTERVIEW_RESEARCH_AND_EDITORIAL_GUIDE.md): repository-first realistic work, independent observable challenges, Docker-first local execution, deterministic tests, explicit cost gates for cloud, no committed secrets, and mandatory teardown for live resources.

Ideas are proposals until a contributor supplies scope, acceptance criteria, local validation and documentation. No roadmap item is a promise of schedule or completion.
